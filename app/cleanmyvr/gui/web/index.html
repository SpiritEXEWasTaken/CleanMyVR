Connect your headset

CleanMyVR talks to your Quest over USB. Nothing changes until you choose an action.

  1. Turn on Developer Mode
    Meta Horizon phone app → Devices → your headset → Headset settings → Developer mode.
  2. Plug the headset into this computer
    Use a USB cable that carries data (some charging cables don't).
  3. Put the headset on and choose Allow
    Tick “Always allow from this computer” in the “Allow USB debugging?” prompt.
Press Connect when you're ready.

Backup

Copies photos and videos (any profile) plus game saves on shared storage to this computer. Every file is SHA-256 checked against the headset.

Saves inside apps' private storage can't be read by any tool; Meta Store games usually back those up to the cloud (Settings → System → Backup).
